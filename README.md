# MyReactBoilerplate

A starter template for React apps that I made for my own projects. Create React App with Material-UI, Overmind state, React Router, a fetch helper and GitHub Pages deploy already set up, so a new project starts with the boring parts done. It is an older setup (React 16, Material-UI 4).

**Live demo:** https://p32929.github.io/MyReactBoilerplate/

## What's included

1. **ReactJS** (Create React App)
2. **Material UI** components
3. **Overmind** for state management
4. **React Router** for routing
5. **FayFetch** as the HTTP wrapper
6. **gh-pages:** `npm run deploy` publishes to GitHub Pages

## Getting started

```bash
git clone https://github.com/p32929/MyReactBoilerplate.git
cd MyReactBoilerplate
npm install
npm start
```

Deploy it:

```bash
npm run predeploy
npm run deploy
```
